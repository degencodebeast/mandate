# The human creates the mandate, not the agent

The human creates the mandate via a dashboard or CLI before the agent runs. This makes the demo story clear: a human gives an agent economic authority, the agent spends within that authority, the human sees every payment. We rejected agent-created mandates (removes the human from the loop; the judge asks "who is responsible if the agent overspends?" with no answer; a self-imposed limit is not enforceable) and dual-creation (adds complexity for no demo value in a 2-day build).
