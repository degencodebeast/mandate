# Per-user Circle Agent Wallet, not shared or user-supplied

Each user gets a Circle Agent Wallet when they sign up. The mandate references the user's wallet. The agent operates the wallet within the mandate constraints. The user owns the wallet. Mandate controls spending. We rejected a shared wallet (users cannot withdraw their own funds, not production-ready) and user-supplied wallets (requires wallet connection flows like MetaMask/WalletConnect, adds complexity that does not serve the core product).
